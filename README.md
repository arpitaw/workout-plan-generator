# Workout Plan Generator 🏋️

An AI-powered web application that generates personalized workout plans using Groq's language models. Built with Streamlit for an intuitive, user-friendly interface.

## 🚀 Features

- **AI-Powered Workouts**: Generate custom exercise routines using advanced LLMs
- **Personalized Plans**: Tailored recommendations based on fitness level, goals, and preferences
- **Multiple Fitness Goals**: Support for strength training, weight loss, muscle building, and endurance
- **Easy to Use**: Clean, intuitive interface with no steep learning curve
- **Real-time Generation**: Instant workout plan generation

## 🛠️ Tech Stack

- **Frontend**: Streamlit
- **Backend**: Python
- **AI Model**: Groq API (Open AI models)
- **Environment Management**: Python venv
